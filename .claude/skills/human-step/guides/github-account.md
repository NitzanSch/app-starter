# Create a GitHub account

Why: GitHub keeps a safe copy of the app online. It's free.

1. Go to https://github.com/signup.
2. Enter your email, create a password, and choose a username. The username is public, so keep it simple.
3. Enter the code GitHub emails you.
4. If it asks about plans or personalization, choose **Free** and skip the rest.

You'll know it worked when you see the GitHub home page, logged in.
