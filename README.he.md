# App Starter

[English](README.md)

בונים אפליקציית אינטרנט אמיתית פשוט מתיאור של מה שרוצים. לא צריך לדעת לתכנת: Claude הוא מהנדס התוכנה שלכם, ואתם מחליטים מה האפליקציה צריכה להיות.

## מתחילים כאן

**מה צריך:** מנוי Claude בתשלום ו[אפליקציית Claude למחשב](https://claude.ai/download). המדריך הזה מניח שאתם על Windows, והוא עובד גם על Mac.

1. פתחו את אפליקציית Claude, היכנסו לחשבון ולחצו על הלשונית **Code**.
2. מתחת לתיבת ההודעה, ודאו שנבחרה הרצה על המחשב שלכם (local).
3. ליד זה, לחצו על הכפתור **folder** וצרו תיקייה חדשה וריקה לאפליקציה, למשל `C:\Users\YourName\Apps\my-app`. לכל אפליקציה יש תיקייה משלה. אם אפשר, הימנעו מתיקיות שמסונכרנות עם OneDrive.
4. מתחת לתיבת ההודעה, לחצו על כפתור המצב ובחרו **Auto**, כדי ש-Claude לא יעצור לשאול על כל צעד קטן.
5. לחצו על כפתור ההעתקה בתיבה שלמטה, הדביקו את הטקסט ב-Claude ולחצו **Enter**.

```text
להקים בתיקייה הזו פרויקט אפליקציה חדש מתוך התבנית שנמצאת בכתובת https://github.com/NitzanSch/app-starter

פיתוח תוכנה הוא לא התחום שלי, אז צריך לדבר איתי בשפה פשוטה ולא טכנית, באותה שפה שבה כתובות ההודעות שלי. אפשר להניח שאין לי אף חשבון ושום דבר לא מותקן אצלי. אף פעם לא לחכות בשקט: אם בשלב כלשהו עלולה להופיע בקשת אישור של Windows, קודם צריך להגיד לי, כי היא עלולה להיפתח מאחורי החלון הזה. צריך לבצע את הפעולות האלה לפי הסדר:

1. לבדוק את מערכת ההפעלה שלי. אם Git או GitHub CLI חסרים, יש לך את האישור שלי להתקין אותם באמצעות winget. את ההתקנות צריך להריץ ברקע.
2. לשכפל את התבנית ישירות לתוך התיקייה הזו, לא לתוך תת-תיקייה.
3. לקרוא את AGENTS.md ולפעול לפיו מעכשיו והלאה. השיחה הזו התחילה לפני שהקבצים היו קיימים, ולכן צריך לקרוא skills ישירות מהנתיב .claude/skills/<name>/SKILL.md
4. לבקש ממני שם קצר לאפליקציה שלי. אחר כך לחבר את GitHub לפי ה-skill בשם phase-1-local: יש לך את האישור שלי ליצור מאגר GitHub פרטי חדש (private repository) תחת החשבון שלי עבור האפליקציה הזו, לשנות את ה-remote בשם origin של התיקייה הזו כך שיצביע על המאגר הזה, ולדחוף (push) את הפרויקט הזה אליו. לעולם לא לדחוף (push) לתבנית.
5. אחר כך לפעול לפי ה-skill בשם start-app ולראיין אותי על האפליקציה שלי.
```

זהו. מכאן Claude ממשיך.

## מה קורה אחר כך

1. קודם Claude מכין את המחשב שלכם. ייתכן ש-Windows יבקש מכם ללחוץ על **Yes** פעם או פעמיים.
2. אחר כך Claude שואל על האפליקציה שלכם, ומה אתם רוצים שהיא תעשה.
3. אתם רואים גרסה ראשונה במחשב שלכם.
4. ואז Claude מעלה אותה לאינטרנט, ואתם פותחים אותה בטלפון.
5. לבסוף Claude מוסיף שמירת נתונים וכניסה לחשבון אם האפליקציה צריכה אותן, ושואל מה תרצו בהמשך.

## כש-Claude שואל אתכם משהו

את ההחלטות הטכניות Claude מקבל בעצמו. הוא אמור לעצור אתכם רק בשביל אחד מהדברים האלה, ולומר איזה מהם:

- **הטעם שלכם:** איך משהו צריך להיראות או לעבוד
- **כסף:** כל דבר שעלול לעלות לכם כסף
- **משהו שרק אתם יכולים לעשות:** כמו להיכנס לחשבון או ליצור חשבון
- **סיכון למחשב שלכם:** הוא מסביר למה, ושואל קודם

תמיד אפשר לומר "עדיף לי לעשות את זה אחרת", או לשאול "מה זה אומר?".

אם Claude מבקש מכם לאשר משהו ונותן לכם משפט מדויק לענות בו, השתמשו במשפט הזה. בדיקת הבטיחות של Claude צריכה לראות שאתם מציינים את הפעולה הספציפית.

## חוזרים מאוחר יותר

פתחו את הלשונית **Code**, בחרו את אותה תיקייה, ודאו שהמצב הוא **Auto**, וכתבו "בואו נמשיך". כל מה ש-Claude צריך לזכור שמור בתוך הפרויקט עצמו.

## טוב לדעת

- **חשבונות:** תצטרכו חשבונות GitHub ו-Google בחינם. Claude ילווה אתכם ביצירה שלהם או בכניסה אליהם.
- **שפה:** כתבו ל-Claude בשפה שלכם, והוא יענה באותה שפה. קובצי העבודה שלו נשארים באנגלית, ואף פעם לא תצטרכו לקרוא אותם.
- **עלות:** ל-Firebase, שירות האירוח, יש תוכנית חינמית שמתאימה לאפליקציה קטנה. Claude שואל לפני כל דבר שעלול לעלות כסף.
- **הקוד שלכם:** הוא שמור במאגר GitHub הפרטי שלכם, ורק אתם יכולים לראות אותו.
- **בטיחות:** במצב Auto יש בדיקת בטיחות, אבל היא לא ערובה. Claude יכול להריץ פקודות במחשב שלכם בלי לשאול בכל פעם, אז השתמשו בזה במחשב שנוח לכם איתו ושימו עין על מה שקורה.
- **סיסמאות:** אף פעם אל תדביקו בצ'אט סיסמאות, מספרי כרטיס או מפתחות סודיים. במקום זה, Claude יפנה אתכם לאתר הנכון.

## מה יש בפרויקט הזה

|---|---|
